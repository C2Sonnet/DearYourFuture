# キミの未来へ — Toward Your Future

![キミの未来へ・メインビジュアル](public/assets/kimi-no-mirai-title.jpg)

**「やりたい」を「できる」へ近づけるために。** 製菓・製パンなどの仕事を目指す方が、企業・求人情報を比較し、応募や選考の予定を自分のペースで整理できる、日本語の就職活動支援サイトです。

**バージョン：v2.6.1** ／ 作者：[光と影のソネット（キセキ）(@C2Sonnet)](https://im.c2s.me)

## 主な機能（一般ユーザー向け）

- **企業・求人を探す**：キーワード、所在地、職種、雇用条件などから調べ、情報源を確認できます。
- **企業・求人を詳しく確認する**：業務内容、給与、勤務先、応募条件、口コミの確認状況などを参照します。公開された求人は、必ずしも現在の募集枠を保証しません。
- **比較・お気に入り**：気になる求人・企業を保存し、比較カートで特徴を比べます。
- **応募・選考を管理する**：選考の段階、予定、履歴、メモなどを記録し、次の行動を整理します。
- **おすすめと更新情報**：参考候補や情報の更新を確認します。応募資格・通勤時間の保証ではありません。
- **メッセージと通知**：チャット風の返信機能（MinaHelperのシステム通知は返信不可）を備えたサイト内メッセージ、通知設定、アカウント情報を利用できます。
- **見やすい画面**：PC・スマートフォン対応、ライト／ダークモード、固定ヘッダーなど。
- **サイト資源**：ナビの「その他」から背景画像を日付別に閲覧。クリックで拡大表示、ダウンロードボタンで保存できます。
- **キミへ**：許可されたアカウントだけに表示される手紙です。一般ユーザー全員には公開されません。

各画面の操作手順は [一般ユーザー向け操作ガイド](docs/USER_GUIDE.md) を参照してください。管理者向け機能はこの機能一覧に含めません。

## 技術・動作環境

PHP **8.4以上**、MySQL（PDO MySQL）、Argon2id、HTTPS、`public/`をWeb公開ルートとするサーバーを使用します。OSやPHP拡張・権限の詳細は [INSTALL.md](INSTALL.md) を確認してください。リポジトリ内にパスワード・DB設定・認証キーは含まれません。

## 初期インストール（概要）

1. リポジトリZIPを展開して、Web公開ルートを `public/` に設定します。親ディレクトリ（`app/`, `database/`, `resources/`, `docs/`, `waterfall/`など）は公開しません。
2. PHP・DB権限・HTTPSを確認し、**既存データのない新しい専用DB**を用意します。以前のDBを空にしたり流用したりしないでください。
3. `php tools/install/check-install-package.php --json` で初期企業・研究データのSQLと原典13件を検査します。
4. サーバー上で `php tools/install/create-token.php` を実行し、60分有効の初回セットアップトークンを安全に取得します。
5. ブラウザで `/initial` を開き、初期開発者アカウントとDB接続先を登録します。**初期インストール時に企業・求人データが自動登録されます。別途SQLを手作業で投入する必要はありません。**
6. ログイン後にサイト設定・メール等の必要な初期設定を確認します。

設置処理は従来の構成のままです。初回DBには固定されたR06初期企業103件・求人128件などが登録され、サイトの企業・求人表示では、サイト採用済みのR07 Batch66（113事業者・146求人）を正本として利用します。この2つは内部の管理階層が異なり、応募受付中を保証するものではありません。

**途中で設置が停止した場合**：DB・`storage/system/install.incomplete`・ロックファイル・暗号鍵を削除して再試行しないでください。診断と非破壊の復旧手順は [INSTALL.md](INSTALL.md) を参照してください。

## アップデート・情報導入・アウトプット

- **アップデート**：本番DBと非公開ストレージを事前にバックアップし、現行のバージョン／Schema／署名を確認したうえで管理者が実施します。単なるZIPの上書きでDBや権限が移行されるわけではありません。手順は [INSTALL.md](INSTALL.md)。
- **情報導入**：初期設置では固定研究原典とSQLを検証して自動導入します。運用後に追加データを導入する場合は管理者の審査・承認を経て、既存IDと本人編集内容を保護します。詳細は [情報導入・出力ガイド](docs/DATA_AND_EXPORT.md)。
- **アウトプット**：画面の表示・比較、アプリに用意されたダウンロード／エクスポート機能、管理者によるバックアップを区別します。画面上の保存・出力は権限と機能の範囲内に限られます。詳細は [情報導入・出力ガイド](docs/DATA_AND_EXPORT.md)。

## 情報の範囲と注意事項

サイトで採用する確定データ集は **R07 Batch66（2026-11-24）** の113事業者・146求人です。情報収集側では依然として審査未完了の作業版であり、サイトへの採用は個別の応募可能性の確認を意味しません。企業の存在、採用枠の現在の有無、個別応募条件、外国籍の採用可否、正確な通勤所要時間は原典の確認状態に依存します。必ず応募前に公式採用ページへ確認してください。旧R06原典と初期SQLは検証用の固定ファイルとして保持しています。
