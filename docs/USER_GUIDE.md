# 一般ユーザー操作ガイド

このガイドはログインして利用する人のためのものです。管理者の設定操作や研究データ承認操作は扱いません。

## 1. サイトを開く・ログインする

1. サイトURLを開き、ログイン画面からユーザーIDまたはメールアドレスとパスワードを入力します。
2. ログイン後、右上のユーザーメニューから「ユーザーセンター」「プロフィール」「セキュリティ」を開けます。
3. 未ログイン閲覧が禁止されている場合は、閲覧前にログインが必要です。

## 2. 企業・求人を調べる

1. 「企業を探す」または企業・求人の一覧を開きます。
2. キーワードや表示されている条件で絞り込みます。
3. 企業詳細では所在地・事業内容・公開出典・口コミの確認状況を、求人詳細では雇用形態・職務・給与・勤務地・応募条件を確認します。
4. 求人の「2027卒」表記は採用の残枠や本人の応募資格を保証しません。出典を開いて必ず再確認してください。

## 3. お気に入りと比較

1. 候補の企業・求人に「お気に入り」や比較への追加操作があれば選択します。
2. 比較カートの「求人比較」「企業比較」を開き、候補同士の違いを見ます。
3. 比較候補を外す場合は、比較カートから個別削除または一括削除を選択します。

## 4. 応募・選考・予定の管理

1. ユーザーメニューの「就活管理」を開きます。
2. 対象企業や応募状況を登録し、選考段階・メモ・面接予定等を記録します。
3. 「予定・タイムライン」で今後の予定を確認できます。記録は他社への応募操作を代行するものではありません。

## 5. メッセージと通知

1. ユーザーメニューの「メッセージ」で受信内容を確認します。
2. 「メッセージ設定」「メール設定」から受信・通知に関する設定を確認します。メールの到達はサーバーのSMTP設定に依存します。

## 6. アカウントと画面表示

1. 「プロフィール」で表示名や設定可能な本人情報を確認します。
2. 「セキュリティ」でパスワードを変更できます。現在のパスワードが必要な操作があります。
3. 画面右下の切り替えからライト／ダークモードを変更できます。スマートフォンではメニューを開いて移動します。

## 7. 「キミへ」について

この手紙は許可されたアカウントにだけ表示されます。対象外ユーザーにはメニューが表示されません。

## 8. 不具合が起きた場合

ログインを繰り返す、情報が古い、メールが届かない等の場合はエラーメッセージと発生時間を管理者に伝えてください。パスワード・トークンや個人情報をそのまま送らないでください。


## サイト資源・背景画像

「その他」→「サイト資源」を選ぶと、公開されたサイト背景画像が日付ごとに表示されます。画像をクリックすると拡大表示し、別の「画像をダウンロード」から保存できます。横長と縦長の画像は区別して表示します。

## メッセージと画面内のお知らせ

受信箱から通常の個別メッセージを開くと、関連する会話を時系列で確認・返信できます。MinaHelperからのシステム通知には返信できません。ログイン時の案内では前回ログインの時刻とIPが本人に表示される場合があります。時刻によって休息の案内が表示されることもあります。

## 選考状況の更新

企業カードにある「現在の選考状況」を選び、その下にある「状態を更新」から保存します。表示されている求人の募集状態とは別の本人専用記録です。
