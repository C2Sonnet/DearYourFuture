# プライバシーについて

「キミの未来へ」では、アカウント認証、セキュリティ確認、求人・企業の閲覧、検討・応募の管理のため、利用状況を記録します。

ログインした日時と接続元IPアドレスは認証履歴として保存されます。ログイン後には本人へ前回ログイン時刻・前回IP・現在のIPを表示する場合があります。利用者の閲覧履歴、お気に入り、応募・選考状況はアカウントに結び付けて記録されます。これらは一般公開されませんが、権限と監査が設定された運営者が、サポート・管理・不正利用対策等の必要な範囲で取り扱う場合があります。

サイト内メッセージにはシステムからの案内が含まれます。深夜の休息案内はサーバーに設定された時刻を基準に表示され、同じ日の重複表示を抑制するための記録を使います。時刻の設定やアカウントの役割によって表示が変わる場合があります。

企業・求人情報の確認日時と採用状況は実際の採用可否の保証ではありません。個人の応募メモ等の取り扱いについて不明な点がある場合は、サイトの運営者へお問い合わせください。保存期間、削除・訂正の運用ルールは設置先のプライバシーポリシーにも従います。
