# 情報の導入・出力とデータ保護

正式稼働版v3.1.0では情報収集正式版d2.0.0（Batch143基準、146企業原レコード・181求人原レコード）を使用します。正規化145企業群・180求人群、比較79求人。比較情報収録率278/316（88.0%）、不足38項目と品質8PASS/8HOLDを維持します。公開ソースZIPには研究原典・初期SQL・稼働用スナップショット・派生索引・採用台帳を収録しません。公開用ZIPからは設置・原典同期を実行しないでください。

実運用での情報導入は原典の版・ハッシュ・ID・公開条件・既存利用者データの保護を確認し、運用者の承認を受けて行います。公開された求人の現在の受付や個人の応募資格を保証するものではありません。
