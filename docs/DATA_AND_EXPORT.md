# 情報の導入・出力とデータ保護

## 初期データはインストーラが自動登録

本版は既存のSchema41と固定R06初期データSQLを変更しません。新規の空DBへ初回インストールすると、初期企業10件とR06の正規化企業・求人情報（会社103件・求人128件）が自動的に登録されます。原典検証ファイル11件、SQL本体2件のハッシュ検査を開始前に実施します。研究データを別に投入する手順は不要です。

最新版の表示カタログは非公開の `resources/research/r07-current/` に保存された **R07 Batch50 112事業者・143求人** を参照します。元IDの対応を保ち、DB上の本人編集、採用管理履歴、メッセージを自動上書きしません。サイト側でR07 Batch50を確定データ集として採用しています。研究側の正式確定・求人ごとの採用条件確認とは別の判断であり、原典の未検証フラグは維持します。採用記録は `resources/research/SITE_CATALOGUE_ADOPTION_v2.0.0.json` に保存されています。

## 初期設置後の情報導入

求人の「掲載」「募集終了」「応募可能」「推薦可能」を区別します。運用中に原典を更新する場合は、変更対象の元ID、情報出典、給与・雇用条件の適用年度、既存データとの重複を確認します。必要な場合は管理者の明示的な審査・承認後に既存の管理機能から導入します。

**避けること**：公開されたCSV・JSONをDBへ直接実行、初期設置用SQLを稼働中DBへ再投入、IDの再利用、既存企業の削除後再作成、他の応募者の個人データへの無断上書き。

## 一般ユーザーの出力・確認

企業・求人の閲覧、比較ページ、各画面の表示・ダウンロード機能（提供される場合）を利用します。保存・出力の可否は表示中の画面と権限に従います。データの複製が可能な場合も出典の利用条件を確認してください。

## 原典ファイルの役割

`docs/research_snapshot_d1.0.4_R06/` 等は初回設置の固定ハッシュ照合に必要な原典です。`resources/research/r07-current/` は現在の表示カタログと根拠を保持します。両者は役割が異なるため、どちらも削除しないでください。
